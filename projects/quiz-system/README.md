# 🧠 Python Quiz System

A simple question and answer system built with Python.  
This project validates user input using a function, checks answers and calculates the final score in percentage.

---

## 🚀 Features

- Multiple choice questions
- Input validation
- Score system
- Percentage result
- User-friendly interface

---

## 📌 Technologies

- Python 3

---

## ▶ How to run

1. Clone this repository:

   git clone https://github.com/EduardoKWG/python_from_zero_to_data.git

2. Navigate to the quiz project folder:

   cd python_from_zero_to_data/projects/quiz-system

3. Run the script:

   python quiz.py
