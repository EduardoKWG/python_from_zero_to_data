## 🧩 While Loop Challenges

### 🎯 Objective
Practice using `while` loops to iterate over data and control program flow.

---

## 🔤 String Iteration Challenge

### 🛠️ Concepts Used
- While loops
- String indexing
- String length with `len()`
- Conditional logic

### What this challenge does:
- Iterates through each character of a string
- Appends an asterisk (`*`) after each character
- Preserves spaces without adding an asterisk

## 🛒 Shopping List Challenge

### 🛠️ Concepts Used
- While loops
- Input validation
- Error handling
- Conditional logic

### What this challenge does:
- Adds items to a shopping list
- Deletes items by index
